# nexy-apps.github.io

nexy のアプリの「版の一覧」（Sparkle の `appcast.xml`）を、GitHub Pages で配る置き場所です。

| アプリ | 版の一覧の URL |
|---|---|
| Pinshelf | https://nexy-apps.github.io/pinshelf/appcast.xml |
| Pinshot | https://nexy-apps.github.io/pinshot/appcast.xml |
| Pinstage | https://nexy-apps.github.io/pinstage/appcast.xml |

- この URL はアプリの中に書き込まれ、配ったあとは変えられません。このリポジトリの名前・組織の名前・フォルダの名前を変えないでください。
- 各アプリの `make publish` が、ここへ版の一覧を書き込みます。手で編集しないでください。
- アプリ本体（DMG・zip）は、各アプリのリポジトリの Releases にあります。
